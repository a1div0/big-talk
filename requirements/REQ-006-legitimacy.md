## Формулировка
Цепочка источника каждого полномочия замкнута на аксиомы; для каждого состязательного решения признание проигрыша — рациональный выбор [[проигравшей стороны]]; у каждого элемента есть индикаторы утраты [[легитимности]], не подавляемые самим органом.

## Критерий приёмки
TEST-006 проходит для всех EL.
