## Формулировка
Для каждого наблюдаемого индикатора известен способ накрутки и его цена; либо цена выше выгоды, либо есть контр-индикатор, либо риск принят через ADR.

## Критерий приёмки
TEST-005 проходит.

## Вывод
Индикаторы легитимности (REQ-006) бесполезны, если их можно накрутить; медианный актор (AX-002) будет накручивать.
