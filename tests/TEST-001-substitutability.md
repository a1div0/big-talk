## Назначение
Ловит конструкции, которые работают только при определённых людях: «мудрый суд», «ответственный
председатель», «добросовестная комиссия». Если после замены всех должностных лиц на медианных
носителей той же роли с их собственными интересами элемент перестаёт выполнять назначение —
это не система, а договорённость.

## Входы
Целевой EL; ACT (kind: role) с секцией «Как ведёт себя медианный представитель»; ASM о людях.

## Процедура
1. Выписать все роли, участвующие в элементе.
2. Для каждой роли взять описание медианного представителя из ACT (если его нет — это уже DEF на ACT).
3. Пройти правила элемента по порядку, на каждом шаге спрашивая: что сделает медианный носитель роли,
   максимизируя свой интерес в рамках правил? Есть ли у него причина сделать то, что предполагает правило?
4. Отметить шаги, где правило предполагает поведение, за которое медианному носителю не платят
   (репутацией, полномочиями, санкцией, карьерой).
5. Отдельно проверить: есть ли роль, отказ или сговор которой обрушивает элемент целиком.

## Рубрика
| критерий | 0 | 1 | 2 |
|---|---|---|---|
| Все роли описаны в ACT с медианным поведением | нет | частично | да |
| Каждый шаг совместим с интересом исполнителя | ≥1 шаг требует альтруизма* | шаги с слабым стимулом | все шаги стимулированы |
| Нет единой точки отказа в лице одной роли | есть, без компенсации | есть, есть компенсация | нет |
| Санкции за уклонение исполнимы другим медианным актором | нет | частично | да |

Порог прохождения: 6 из 8. Любой 0 по критерию с * — провал.

## Формат результата
Файл `tests/runs/RUN-NNNN-<TEST>-<EL>.md` по шаблону RUN. Каждый балл 0 или 1 — отдельный DEF или OQ со ссылкой на пункт правил EL.
