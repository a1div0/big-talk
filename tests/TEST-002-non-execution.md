## Назначение
Ловит процедуры без определённого исхода при срыве: выборы не назначены, суд не собрался,
бюджет не принят, назначение не сделано в срок. Молчание спецификации в этой точке — самая
частая дыра, через которую входит чрезвычайное правление.

## Входы
Целевой EL, секция «Поведение при неисполнении»; EL, от которых он зависит.

## Процедура
1. Выписать каждую процедуру элемента с её сроком и ответственной ролью.
2. Для каждой: предположить, что ответственный не сделал ничего. Кто исполняет полномочия? Как долго?
3. Кто и по какой процедуре может перезапустить? Есть ли у него стимул?
4. Проверить рекурсию: процедура перезапуска тоже может быть не исполнена — где дно?
5. Проверить, не выгодно ли какому-то актору срыв процедуры (сравнить с DIS/THR).

## Рубрика
| критерий | 0 | 1 | 2 |
|---|---|---|---|
| Исход при неисполнении определён для каждой процедуры* | есть молчание | определён, но неясен срок | определён полностью |
| Есть роль с стимулом перезапустить | нет | есть, стимул слабый | есть, стимул сильный |
| Рекурсия конечна (дно за ≤2 уровня) | бесконечна | ≤3 уровня | ≤2 уровня |
| Срыв не выгоден ни одному актору из ACT | выгоден, без компенсации | выгоден, компенсировано | не выгоден |

Порог прохождения: 6 из 8. Любой 0 по критерию с * — провал.

## Формат результата
Файл `tests/runs/RUN-NNNN-<TEST>-<EL>.md` по шаблону RUN. Каждый балл 0 или 1 — отдельный DEF или OQ со ссылкой на пункт правил EL.
