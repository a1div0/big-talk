## Назначение
Ловит взаимоблокировки (орган A ждёт органа B, B ждёт A), паралич при равенстве голосов,
отсутствие кворума, отставку всех членов, бесконечные обжалования. И «мягкую» деградацию:
элемент формально работает, но всё дольше и всё хуже.

## Входы
Целевой EL и все EL из depends_on; THR; ASM о ресурсах.

## Процедура
1. Построить граф зависимостей решений внутри элемента и между ним и depends_on.
2. Найти циклы. Для каждого цикла: есть ли разрывающий механизм (срок, жребий, дефолт, вышестоящий)?
3. Перебрать стандартные тупики: равенство голосов, отсутствие кворума, массовая отставка,
   отказ признать результат, параллельные претенденты на одну должность.
4. Для деградации: что происходит, если бюджет элемента сокращён вдвое? Если половина ролей вакантна год?
5. Записать, какой тупик самый дешёвый для организации намеренно (вход для TEST-010).

## Рубрика
| критерий | 0 | 1 | 2 |
|---|---|---|---|
| У каждого цикла есть разрывающий механизм* | нет | есть, зависит от доброй воли | есть, автоматический |
| Стандартные тупики покрыты | <половина | большинство | все |
| Деградация не переводит элемент в другой режим власти | переводит (чрезвычайный) | переводит с ограничением | не переводит |
| Тупик наблюдаем извне (индикатор) | нет | косвенно | прямо |

Порог прохождения: 6 из 8. Любой 0 по критерию с * — провал.
