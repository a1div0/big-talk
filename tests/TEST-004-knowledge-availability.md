## Назначение
Ловит правила вида «назначить компетентного», «оценить соразмерность», «действовать в
интересах общества», исполнение которых требует знания, недоступного исполнителю в момент
исполнения, или знания, которым он не располагает как медианный носитель роли.

## Входы
Целевой EL; ACT для каждой роли (ресурсы, информация); GLOSSARY.

## Процедура
1. Для каждого правила выписать, какое знание нужно, чтобы его исполнить и чтобы проверить исполнение.
2. Для каждого знания: откуда оно берётся? Есть ли роль или процедура, которая его порождает?
3. Отметить правила, где знание существует только в голове исполнителя (непроверяемо).
4. Отметить правила, где знание требует экспертизы, которой у медианного носителя роли нет,
   и нет процедуры её получения.
5. Отдельно: термины без определения в глоссарии — это тоже недоступное знание.

## Рубрика
| критерий | 0 | 1 | 2 |
|---|---|---|---|
| Каждое требуемое знание имеет источник в системе* | ≥1 правило без источника | источник неформален | все есть |
| Исполнение проверяемо третьей стороной | нет | частично | да |
| Экспертиза либо не нужна, либо есть процедура её получения | нужна, процедуры нет | процедура слабая | есть |
| Все термины определены | нет | частично | да |

Порог прохождения: 6 из 8. Любой 0 по критерию с * — провал.
