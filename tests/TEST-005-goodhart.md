## Назначение
Каждый наблюдаемый индикатор элемента — потенциальная цель. Тест проверяет, что для каждого
индикатора известен способ его накрутить, оценена цена накрутки и есть либо второй, слабо
коррелированный индикатор, либо явное решение принять риск.

## Входы
Секция «Наблюдаемые индикаторы» целевого EL; ACT с интересами; deploy/preregistration.md.

## Процедура
1. Выписать все индикаторы элемента и индикаторы из пре-регистрации, относящиеся к нему.
2. Для каждого: кто выигрывает от высокого значения? Что самое дешёвое он может сделать,
   чтобы поднять значение, не улучшая то, что индикатор должен измерять?
3. Оценить цену накрутки относительно выгоды.
4. Проверить, есть ли контр-индикатор, который при накрутке ухудшится.
5. Проверить, привязаны ли к индикатору санкции или награды (если да — риск выше).

## Рубрика
| критерий | 0 | 1 | 2 |
|---|---|---|---|
| Для каждого индикатора описан способ накрутки | нет | частично | да |
| Цена накрутки > выгоды или есть контр-индикатор* | есть дешёвая накрутка без контр-индикатора | контр-индикатор слабый | да |
| Индикаторы с санкциями/наградами защищены отдельно | нет | частично | да |
| Индикаторы совпадают с пре-регистрацией пилота | расходятся | частично | совпадают |

Порог прохождения: 6 из 8. Любой 0 по критерию с * — провал.

## Формат результата
Файл `tests/runs/RUN-NNNN-<TEST>-<EL>.md` по шаблону RUN. Каждый балл 0 или 1 — отдельный DEF или OQ со ссылкой на пункт правил EL.
