## Назначение
Проверяет три вещи: у каждого полномочия есть прослеживаемый источник; у каждого состязания
есть процедура, по которой проигравшая сторона рационально признаёт проигрыш; у элемента есть
наблюдаемые индикаторы утраты легитимности, которые нельзя подавить административно.

## Входы
Целевой EL; AX; ACT; DIS (кто считает элемент нелегитимным уже сейчас).

## Процедура
1. Для каждого полномочия элемента построить цепочку: кто дал → кому → по какой процедуре → до AX.
2. Для каждого состязательного решения (выборы, суд, распределение): что получает проигравший,
   признав проигрыш, и что теряет, оспорив силой? Почему признание — рациональный выбор?
3. Выписать индикаторы утраты легитимности (явка, исполнение решений, эмиграция, параллельные
   структуры). Можно ли их подавить решением самого органа?
4. Свериться с DIS: есть ли актор, для которого элемент нелегитимен по построению, и что об этом
   сказано в ADR.

## Рубрика
| критерий | 0 | 1 | 2 |
|---|---|---|---|
| Цепочка источника полномочий замкнута на AX* | разрыв | через неформальную ступень | замкнута |
| Признание проигрыша рационально для проигравшего* | нет | при части исходов | при всех исходах |
| Индикаторы утраты не подавляемы самим органом | подавляемы | частично | нет |
| Разногласия по легитимности учтены в ADR | нет | частично | да |

Порог прохождения: 6 из 8. Любой 0 по критерию с * — провал.
