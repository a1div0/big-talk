## Назначение
Ограничивает объём, число ролей, глубину зависимостей и число исключений. Система, которую
нельзя прочитать за вечер и исполнить без юриста, не будет исполнена как написано.

## Входы
budget.yaml; все EL и NORM.

## Процедура
1. Запустить `python tools/lint.py check` — ошибка при превышении любого лимита.
2. Запустить `python tools/lint.py budget` — таблица потребления.
3. При приближении к 90% лимита — открыть OQ: что сокращать.

## Рубрика
| критерий | 0 | 1 | 2 |
|---|---|---|---|
| Все лимиты соблюдены* | превышение | ≥90% | <90% |
| Число исключений не растёт быстрее числа правил | растёт | стабильно | падает |

Порог прохождения: 3 из 4. Любой 0 по критерию с * — провал.

## Формат результата
Файл `tests/runs/RUN-NNNN-<TEST>-<EL>.md` по шаблону RUN. Каждый балл 0 или 1 — отдельный DEF или OQ со ссылкой на пункт правил EL.
