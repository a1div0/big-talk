## Назначение
Ловит пути, по которым текущее большинство или инкумбент может изменить правила так, чтобы
остаться. Проверяет не только формальную процедуру поправок, но и обходные: регламент,
толкование, чрезвычайные полномочия, перенос сроков, изменение состава органа, который
считает голоса.

## Входы
Целевой EL; EL процедуры поправок; THR; PREC с тегом amendment / emergency-powers / quorum.

## Процедура
1. Выписать все способы, которыми правила элемента могут быть изменены: формальные и через
   подчинённые акты (регламент, толкование, кадровые решения).
2. Для каждого способа: кто может его применить, каким большинством, за какое время.
3. Найти самый быстрый путь для инкумбента изменить правило в свою пользу без нарушения буквы.
4. Проверить, симметричны ли правила изменения для инкумбента и оппозиции.
5. Проверить, защищены ли сами правила изменения (мета-уровень) сильнее, чем обычные правила.

## Рубрика
| критерий | 0 | 1 | 2 |
|---|---|---|---|
| Все каналы изменения выписаны, включая подчинённые акты | нет | формальные | все |
| Нет пути, по которому текущее большинство меняет правила за один цикл* | есть | есть с высокой ценой | нет |
| Мета-правила защищены сильнее обычных | нет | равно | сильнее |
| Орган, считающий результат, не может изменить свой состав сам | может | с ограничением | не может |

Порог прохождения: 6 из 8. Любой 0 по критерию с * — провал.
